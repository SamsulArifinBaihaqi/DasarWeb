## 🚀 Panduan Menjalankan Project

1. Pastikan folder repositori berada di dalam root Laragon:
   ```text
   C:\laragon\www\dasarWeb
   ```
2. Buka Laragon dan klik **Start All**.
3. Buka browser dan akses halaman melalui URL:
   - Dashboard Perpustakaan: `http://localhost/dasarWeb/Jobsheet-01/index.html`
   - Praktikum Form: `http://localhost/dasarWeb/P1/buatForm.html`
   - Praktikum Tabel: `http://localhost/dasarWeb/P1/buatTabel.html`
